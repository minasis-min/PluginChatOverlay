# Plugin Chat Overlay 1.0

Dalamudプラグインのチャット通知を専用ウィンドウに表示します。作者表示は **min**、著作権者・公開名は **Minasis** です。

## インストール

Dalamud設定のカスタムプラグインリポジトリへ、次のURLを追加してください。

`https://raw.githubusercontent.com/minasis-min/DalamudPlugins/main/pluginmaster.json`

プラグイン一覧から **Plugin Chat Overlay** をインストールします。公式Dalamudリポジトリへの登録は行っていません。開発版を使っていた場合は、先に無効化して二重読み込みを避けてください。

`/pluginchatoverlay config` を実行し、「基本」でチャット分離を有効にします。初期状態はOFFです。チャット窓を閉じた場合は `/pluginchatoverlay` で再表示できます。

## 機能・操作

- タブによるログの振り分け、独立ウィンドウ化、他ウィンドウへの統合。独立窓の幅・高さを数値指定できます。
- タイトル・タブのドラッグで移動。空白のログ欄をドラッグしても窓は動きません。移動・サイズ変更の許可、スナップ、タイトル・タブの非表示に対応します。
- タイトルバー表示時はDalamud標準の最小化・固定・クリック透過を利用できます。
- 本文の元のチャット色・部分色を保持。時刻は `[23:34]` 形式で、既定は白、本文とは別に色を変更できます。
- フォント、文字サイズ10～36px、行間、背景透明度を設定できます。行間は負値で詰められ、下限は文字サイズの半分、上限は24pxです。
- 文章をドラッグして選択し、Ctrl+Cでコピー。コピー後は選択を解除して窓のフォーカスを外します。ドラッグを離した時の自動コピーは任意設定です。
- 右クリックで「このログをコピー」。履歴全体のコピー・クリアは設定画面から行います。スクロールバーはスクロール中と直後に表示します。
- アイテムリンクへのホバーでゲーム標準ツールチップを表示します。プラグインの設定リンク・マップリンクの操作に対応します。
- カットシーン中・ログアウト中は既定で非表示です。

既定UIはDalamud標準です。「基本」のUI選択でMinasisUIへ切り替えられます。MinasisUIでは左側のカテゴリ一覧の下にUI選択があります。MinasisUIは本体へ組み込まれており、追加プラグインは不要です。

## 設定・制約

設定はDalamud標準のプラグイン設定フォルダの `settings.json` に保存します。履歴はメモリのみで、終了・再ロード時に消えます。保持上限は1,000件です。履歴が多いとメモリ使用量や表示更新の負荷が増えます。窓を閉じていても、分離が有効なら履歴を収集します。

対象環境は **Dalamud 15.0.3.6 / API 15 / Windows x64 / FFXIV 2026.09.15.0000.0000** です。チャット捕捉とネイティブ表示は対応版を確認して動作し、ゲーム・Dalamudの更新時は停止する場合があります。

標準Print系の出力と入手ログへの一部追記が対象です。ゲームへ直接出力するプラグインや、先行フィルターで非表示にされたログは捕捉しません。履歴は捕捉時点の内容を保持し、後続プラグインによる本文の変更は反映しません。

タブの振り分けは導入済みプラグイン名と完全一致する先頭の `[名前]`・`名前:` を認識します。タグのないログは未分類です。分離自体はタグに依存しません。アイテム・プレイヤー・URLのクリック操作は対象外です。

Masked Dalamudとの併用時は、そちらの「他プラグインのシステムメッセージを非表示にする」をOFFにしてください。

クリック透過などで操作できない場合は `/pluginchatoverlay config` から設定を変更できます。`/pluginchatoverlay reset` は窓の位置・サイズを既定値へ戻します。アンインストールはDalamudのプラグイン一覧から行ってください。設定を保持したくない場合は、無効化後にプラグイン設定フォルダ内のファイルを別途削除します。

## ビルド

.NET SDK 10.0.302（10.0.3xxのパッチ更新可）、PowerShell 7、対応版のDalamud SDKが必要です。依存の版・ハッシュは [DEPENDENCIES.md](DEPENDENCIES.md) を参照してください。

対応するDalamudのSDKファイルを `.dependencies/Dalamud-15.0.3.6/` に用意し、リポジトリのルートで実行します。SDKのDLLはこのリポジトリ・配布ZIPには同梱しません。

```powershell
pwsh -NoProfile -File ./scripts/build.ps1
pwsh -NoProfile -File ./scripts/package.ps1
```

配布モードが既定です。成果物は `artifacts/`、一時ファイルは `.work/` に生成します。これらはGitへ登録しません。配布ZIPには本体・manifest・deps.json・アイコン・ライセンス文書だけを含めます。
